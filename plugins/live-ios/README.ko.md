# iOS Live

[English](README.md) | 한국어

> **알파 버전이에요.** 아직 다듬어지지 않은 부분이 있고, 다시 빌드가 필요한 변경이 남아 있으며, 버전마다 동작이 바뀔 수 있어요.

Swift 파일을 저장하면 iOS 시뮬레이터에서 실행 중인 SwiftUI 앱에 약 1초 만에 반영돼요. 같은 프로세스에서 상태도
그대로 유지돼요. 재설치나 재시작이 없어요.

![iOS Live](preview.png)

## 할 수 있는 것

- view의 `body`, 함수, 계산 속성, 비즈니스 로직이 실행 중인 앱에서 바로 바뀌어요.
- 새 view와 새 파일도 반영돼요. 예를 들어 아래쪽 탭에 새 탭을 추가할 수 있어요.
- List 행까지 모든 SwiftUI view가 다시 그려지고, `@State` 같은 저장된 상태는 그대로 남아요.
- 컴파일 오류가 나면 위치와 함께 보여 주고, 앱은 마지막으로 성공한 코드로 계속 실행돼요.
- 저장 공간이 바뀌는 변경(stored property 추가나 삭제, 타입이나 파일 삭제)은 앱을 알아서 다시 빌드하고 다시
  실행해요.

## 쓰는 곳

`.xcodeproj`나 `.xcworkspace`가 있는 프로젝트의 Task를 열고, Moru의 기기 도구에서 시뮬레이터나 연결된 iPhone의 `Live`를 켜면
돼요. 처음에는 앱을 빌드해서 몇 초가 걸리고, 그다음부터는 저장할 때마다 1초 안팎이에요.

## 필요한 것

- Xcode 16 이상과 iOS 시뮬레이터
- SwiftUI 앱. 플러그인은 첫 번째 scheme을 Debug로 자기 폴더에 빌드하고, 프로젝트는 바꾸지 않아요.

## 알려진 한계

- iPhone 실기기는 프로젝트의 Signing 설정에 개발 팀이 있어야 해요. 실제 기기에서는 아직 확인하지 못했어요.
- UIKit 화면은 스스로 다시 그려질 때 바뀐 내용이 보여요.
